# Proyecto Integrador TQA

## Descripción

Este repositorio contiene el código fuente del sistema hospitalario y la documentación relacionada con el Proyecto Integrador de la materia Testing y Aseguramiento de la Calidad (TQA).

## Tecnologías

- Laravel
- Angular
- PostgreSQL

## Objetivo

Organizar el proyecto y sus entregables, documentar las funcionalidades del sistema y registrar las actividades de pruebas de software.

## Actividades

- Documentación del sistema.
- Diseño de casos de prueba.
- Registro de defectos.
- Evidencias y resultados de pruebas.
